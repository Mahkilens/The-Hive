# The Hive

The Hive is an internal WordPress-based platform developed for Wisp Assist, designed to provide tools for accessing ISP databases, assisting customers, and streamlining troubleshooting workflows.

## Features
- ISP tools dashboard
- Troubleshooting workflows
- Monitoring integrations
- Internal documentation access
- Billing and customer system shortcuts

## Project Structure
- `themes/yith-wonder/` → active WordPress theme
- `plugins/` → supporting plugins used by the site

This repository focuses on custom site structure and WordPress-related project assets for The Hive.
