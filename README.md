# The-Wisp-Wordpress-Website-
The Hive is an internal WordPress-based platform developed for Wisp Assist, designed to provide tools for accessing ISP databases, assisting customers, and streamlining troubleshooting workflows. Built and maintained as a solo project, it includes custom themes, plugins, and features tailored for real-world support operations.

# The Hive

Internal WordPress-based platform for Wisp Assist.

## Features
- ISP tools dashboard
- Network troubleshooting shortcuts
- Integrated monitoring tools
- Custom UI built on WordPress

## Requirements
- WordPress
- PHP 8+
- Plugins:
  - WP Dark Mode
